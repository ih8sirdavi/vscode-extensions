# Documentation Essentials

Essential extensions for documentation and markdown

## Included Extensions

- yzhang.markdown-all-in-one
- shd101wyy.markdown-preview-enhanced
- bierner.markdown-mermaid
- bierner.markdown-emoji
- bierner.markdown-footnotes

## Installation

This extension pack works with VS Code and compatible forks (VS Code Insiders, VS Codium, etc).

Search for "Documentation Essentials" in your editor's extensions marketplace.

Or install via CLI:
```bash
# VS Code
code --install-extension ih8sirdavi.documentation-essentials

# VS Code Insiders
code-insiders --install-extension ih8sirdavi.documentation-essentials

# VS Codium
codium --install-extension ih8sirdavi.documentation-essentials

# VS Code OSS
code-oss --install-extension ih8sirdavi.documentation-essentials
```
